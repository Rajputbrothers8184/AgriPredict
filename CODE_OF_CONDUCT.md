# Code of Conduct

## Our pledge

We are a four-person student team building AgriPredict. We pledge to make
participation a harassment-free experience for everyone, regardless of age,
body size, disability, ethnicity, gender identity and expression, level of
experience, nationality, personal appearance, religion, or sexual identity and
orientation.

## Our standards

Examples of behaviour that builds this project:

- Giving and accepting constructive technical feedback
- Respecting each member's ownership of their module
- Being honest about what is finished, broken, or blocked
- Crediting others' work
- Asking questions early rather than silently blocking

Examples of unacceptable behaviour:

- Personal attacks, insults, or dismissive comments
- Harassment in any form, public or private
- Publishing someone's private information without permission
- Committing another member's work as your own
- Deliberately breaking another member's module or branch

## Responsibilities

The repository administrator (the member with admin access to the GitHub repo)
is responsible for clarifying standards and taking fair corrective action,
including removing comments, reverting commits, or escalating to the course
instructor for repeated or serious violations.

## Scope

This code applies in the repository (issues, PRs, commit messages, code
comments) and in any team communication channel used for the project.

## Enforcement

Report unacceptable behaviour to the repository administrator through GitHub's
private channels. All complaints will be reviewed and investigated promptly and
fairly, and the reporter's privacy will be respected. Consequences escalate:
private warning → temporary suspension from the repository → permanent removal
and escalation to the course instructor.
